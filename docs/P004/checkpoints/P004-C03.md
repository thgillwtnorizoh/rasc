## Objective and evidence classification

**OWNER OBSERVATION:** The Modern achievement name resembles installed Motiva Sans with **Bold**, while the description's distinctive lowercase `g` matches the appearance of RASC's **sans-serif** option better than Motiva Sans. Previous experiments adjusted *both* lines together, which cannot test a mixed-family hypothesis. This is a glyph-shape observation, **not** confirmed original font-file identity, computed CSS, font weight or native runtime raster.

**PUBLIC ORIGINAL STATIC CSS AUTHORITY:** The version-labelled extracted [SteamTracking `sp.js` / `sp.css`](https://github.com/SteamTracking/SteamTracking/blob/7857b7d4634423f6343942d07bf53ff6913a8b75/ClientExtracted/steamui/css/sp.css), traced in [P004-C02 source typography research](../C02-source-typography.md), specifies `Motiva Sans` in the Steam UI font stack. AchievementTextSection names and descriptions contain 12px declarations (with normal/light or BasicUI Medium/Normal weights); ShortTemplate.Title may be a separate 11px/500 text node. **DISCREPANCY:** neither investigated rule conclusively establishes 700 Bold for the actually visible title or a Segoe UI desc; runtime-specific font fallback, markup mapping, alternate client style, synthetic face, browser raster and installed font identity are unverified. The WPF generic option uses Windows `SystemFonts.MessageFontFamily`, typically Segoe UI, **not** an assertion that Chromium's CSS generic `sans-serif` is Segoe UI.
