## User-observed requirement and scope

**ENGINEERING selection contract (approved request):** Default Steam preference is (1) `%ProgramFiles(x86)%/Steam`, (2) `%ProgramFiles%/Steam`, (3) any other discovered Steam root (deterministic, case-insensitive lexicographic order). Markers: `steam.exe` and/or `steamui/`. Choose ONE root globally, even if incomplete; do not borrow sound files from another Steam client. A manually selected root overrides the automatic preference until the user chooses **Use automatic**.

**Steam root required assets for diagnostics:** `steam.exe`, `steamui/`, `steamui/sounds/desktop_toast_default.wav`, `steamui/sounds/deck_ui_achievement_toast.wav`. Report **no Steam installation** separately from **selected installation missing these exact files**. The missing-file prompt offers the official Valve Steam download/repair entry point and **Set Steam location…**. A detected Steam may be partially useful: choosing a present sound works even if the other is absent. The prompt does not edit, download or copy files.

**GC requirements:** A candidate game folder contains sibling `csgo.exe` and `csgo_gc/`; only `csgo_gc/achievements.txt` permits starting the existing read-only monitor. If folder and executable are present but text file missing, the prompt explains obtaining GT-610 **or another version with achievement support**, or playing a game with an installed compatible GC to *try* to generate the file. If GC/launcher absent, prompt provides the verified [GT-610 releases](https://github.com/GT-610/csgo-gc/releases) and a **Set CS:GO location…** folder picker. `GT-910` mentioned in the owner prompt is **not an independently verified project identifier**; the existing supported GC authority is GT-610. A manual path is validated by the same sibling contract; no loose `achievements.txt` outside `csgo_gc/` is admitted by the UI.

**Functional production changes:**
- `InstallationDiscovery` is a pure deterministic file-layout selection library (injectable roots), tested independently of WPF.
- Desktop `InstallationLocator` reads HKCU `Software/Valve/Steam` root/SteamExe and common local drive roots; parses a bounded `steamapps/libraryfolders.vdf` read-only and inspects only the immediate children of known `steamapps/common/` folders for GC. Legacy `last-source.txt` is one candidate (not an override). This is **bounded discovery, not a guarantee of locating an arbitrary unknown folder anywhere on every disk**; manual selection handles that.
- `installation-locations.json` in RASC AppData stores **manual Steam root and game root only**, without changing `appearance.json`, `last-source.txt`, `history.db`, source or Valve files. **Rescan** re-checks installed files and current path; **Use automatic** clears the explicit overrides. An active GC monitor keeps its current source and ledger; no silent hot-switch.
- Main UI shows Steam and GC status at launch and an actionable **nonmodal** recovery window if either is incomplete; preview/popups remain available without Steam or GC.
- Default Desktop and Big Picture sounds resolve **directly** to `selectedSteamRoot/steamui/sounds/<expected-name>.wav` when the file is bounded and has RIFF/WAVE header. No hash fixation to an old Steam version; local owner-imported, SHA-approved WAV or private sidecar remains a fallback only if missing. Custom and Off are unchanged. No copy, DLL loading, Steam patching or use of multiple Steam roots for one sound.
