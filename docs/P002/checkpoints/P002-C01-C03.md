## Objective / Supported profile / Functional changes and integrations
Owner confirms current Classic **card design is final unless owner changes it**. No changes to `ClassicToastCard.xaml`, font/colors/icon/text positions or source display size.
Owner identifies unresolved **gap at top–middle of three-card stack**, while middle–bottom looks contiguous. Diagnostic reasoning: at 125% DPI, 94 logical units =117.5 screen pixels and middle card origin rounds to pixel118; top card's half-pixel uncovered edge can appear while middle–bottom independently rounds in opposite direction. Same condition at175% (164.5→165). This matches reported asymmetry but **user's actual DPI/physical seam not measured**.

- `ClassicToastStackWindow.xaml.cs`: adds a source-gradient-matched, anti-aliased-edge-disabled **pixel-snapped background backplate per card**, behind unchanged card contents. The backplate spans the shared integer physical-pixel seam using the existing `ClassicToastPixelGrid.Map` origin and clip edges. Explicit z-order gives lower card/backplate occlusion priority for downward exits. This fills fractional uncovered pixels without moving or distorting icon/text. No new visible borders or margins.
- `ClassicToastHost.cs`: swaps 16ms timer position updates for `CompositionTarget.Rendering` callbacks **only during 450ms slides**. A deadline-based dispatcher wake runs at next six-second hold expiry, avoiding frame callbacks while cards are still. Subscriptions are released after animation and during disposal. The source monotonic `Stopwatch` remains the timeline clock; no fixed frame count assumption or changed easing/duration.
- `ClassicToastScheduler.cs`: exposes `IsAnimating` and `NextHoldDeadline` without altering slide/hold/FIFO algorithms.
- On host Dispose: best-effort `%LOCALAPPDATA%\RASC\last-classic-animation.txt` records unique rendering callbacks, segments, average callback interval-derived rate, and worst interval; doesn't contain personal/game achievement data and does not write to GC or SQLite. Diagnostic is **callback cadence only** (not GPU presentation count).
