## Objective / supported profile / changes and integration

Keep Dataminer [CodePen / LegendaryAchievement](https://codepen.io/Dataminer/pen/pooWzpo) authoritative: original two owner-supplied 64x64 PNGs, 48px icon, 68/88/108px nested light, 6s forward and 18s reverse animations, nine-stop RADIAL gradient, both original CSS box shadows. Its CSS `mask-size:100%` sizes the source mask to each 68x68/88x88 element box.

**Cause found:** C06's WPF `OpacityMask` `ImageBrush` used a *relative* viewbox/viewport. Mask mapping was influenced by the larger painted bounds of overflowing/rotated descendants, letting bright gold rays reach the nominal outer boundary despite near-transparent edge pixels in the original square PNG. C07 explicitly maps 64×64 PNG pixel viewbox to absolute 68×68 and 88×88 DIP viewports. Preserves WPF root mask-box clip, source RGB/alpha stops, shadows, animations, actual icon artwork and every accepted Classic/Modern subsystem.

**New regression:** smoke assertions verify 68/88px absolute mask mapping and actual raster edge pixel softness, not just the presence of a 64px PNG. Native WPF renders at nominal 900/2000ms and verifies animation/gold visibility.

**Browser reference recovery:** The initial headless Chrome fixture with local `file://` PNG `mask-image` sources produced almost shadow-only pixels; source control images revealed this issue. Embedded original PNG base64 data URLs fix it, matching CodePen's source-loading semantics. Two Chrome reference PNGs at 900 and 2000ms now differ by 2,002 color pixels. No source CSS brightness adjustment. Browser is the blank #222 reference, WPF is the production preview star on different background; cross-raster exact numerical equivalence is NOT VERIFIED.
