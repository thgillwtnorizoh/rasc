## Objective / supported profile

- The C03 setting that anchored to ordinary foreground windows is **reverted**. In normal/windowed/maximized desktop operation, existing P002 Classic desktop scale/position and P003-C02 Modern desktop scale/position are restored. No popup is placed INSIDE an ordinary application.
- Only a *visible, focused, monitor-covering fullscreen or borderless-fullscreen* window overrides the desktop work-area anchor. Fullscreen uses that monitor's physical screen edge and its logical display height for automatic sizing. On leaving fullscreen, fallback reverts to pre-C03 baseline without changing the scheduler.
- Classic card artwork and accepted animations untouched. Modern 1/2/3 shared logo slot positioning, wave admission/timing, medal/progress and event store unchanged.
- Modern logo path now follows the recognizably correct Steam mark from Simple Icons CC0 geometry, with trademark notes.
- Rare icon effect now layers the original-CSS-inspired rotating conic gold gradient behind a stationary square halo mask (6-second forward and 18-second reverse diffuse motion), replacing the fake five-dot ring. Actual original desktop-toast CSS reuse is unverified; the WPF blend is approximate.
